thread-priority

See which T3 Code threads matter most. Mark each one high, medium or low, and list them grouped by priority.

View on GitHub
HighPinned in T3 Code so it stays at the top.
MediumTracked, not pinned.
LowTracked, not pinned. Check it later.

Install

/plugin install thread-priority --marketplace jovylle/thread-priority

Type it at the prompt of a Claude Code session. Answer y to add the marketplace, then pick a scope.

Use

/prio                          list threads by priority
/prio high  fix login          mark the matching thread high (and pin it)
/prio low   write docs         mark it low
/prio clear write docs         remove the mark

Match a thread by its id or by part of its title. If more than one thread matches, you get the list and can use an id instead.

Good to know

  • It's an early release (0.1.0). The logic is covered by tests against a simulated T3 Code; it hasn't been verified against every T3 Code version.
  • Priorities are stored on your machine and persist between sessions.
  • It's a slash command. It doesn't add an item to T3 Code's right-click menu on a thread, because mods can't extend that menu.
